# Downloader

A sleek, responsive media downloader and library manager inspired by modern Instagram aesthetics. Inspect links, choose formats and qualities, manage real-time background queues, and access saved files in a clean interface.

## Quick Start

```bash
npm install
npm run dev
```

The application runs on [http://localhost:3000](http://localhost:3000).

## Features

- **Instagram-Grade Minimal UI**: Fluid dark aesthetic, stories-like creator previews, polished micro-interactions, and responsive layout.
- **Link Inspector**: Inspect media details including creator, title, duration, thumbnail, and format options.
- **Queue Management**: Real-time progress tracking with download speeds, ETA, and cancellation controls.
- **Saved Library**: Browse, search, stream, and download saved media files.
- **Advanced Controls**: Customizable subtitles, audio bitrate, containers, filename templates, and network options.
